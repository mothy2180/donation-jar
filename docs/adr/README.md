# Architecture Decision Records

One file per decision, numbered. Template: Context → Decision → Consequences →
Status/Date. Research behind these decisions: PROJECT.md §15 (sources) and the
2026-10-04 and 2026-10-05 journal entries.

Rule: an accepted ADR is not edited — it is superseded by a new ADR. One
exception, made before the repository was first published: on 2026-10-05 a
four-reviewer document review found factual and wording errors, and the affected
ADRs were corrected in place. Each one says so in its status line; where a
correction changed part of a decision, the status line names the change and
PROJECT.md §3 has a 2026-10-05 row for it.
